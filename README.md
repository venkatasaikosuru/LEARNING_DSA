# ⏱️ Algorithm Complexity

### 📊 Sorting Algorithm Complexity

| **Algorithm** | **Best Case** | **Average Case** | **Worst Case** | **Space** | **Stable** |
| ---------------- | ---------------- | ---------------- | ---------------- | ---------------- | ---------------- |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) | ❌ No |
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | ✅ Yes |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | ✅ Yes |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n)* | ❌ No |

> **Note:** Bubble Sort has `O(n)` best-case time when optimized with an early-exit condition. Quick Sort can use `O(n)` recursion stack space in its worst case.

### 🔄 Array Rotation Complexity

| **Operation** | **Time Complexity** | **Space Complexity** |
| ---------------- | ---------------- | ---------------- |
| Left Rotation by 1 | O(n) | O(1)* |

> **Note:** `O(1)` extra space is possible when rotation is performed in-place. Using an additional array requires `O(n)` space.
